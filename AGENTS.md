# Harbor & Pine Supply: orders service

Instructions for any coding agent in this repo (Claude Code, Codex, Copilot).

## Commands
- Test: `npm test` (Node 22). Run it before you say a change is done.

## Rules
- Money is always integer cents. Never use floating point for prices or totals.
- Work on a branch and open a pull request. Never commit to main.
- Never read or print `.env`. Setting names are in `.env.example`.

## Where things are
- Approved plans: `docs/plans/`. Follow the plan; ask before changing it.
- Tests: `test/`, one file per module in `src/`.
